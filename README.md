# Ranjeet Kumar — Interactive Portfolio

## Files
- `index.html` — website content
- `style.css` — responsive styling, dark/light theme
- `script.js` — interactive skill filters, project popups, theme toggle, mobile menu, and copy-email button
- `resume.pdf` — downloadable CV (included if available)

## Preview locally
Open `index.html` in a modern browser. Internet is needed for the optional Google Fonts; the site otherwise works as a static website.

## Publish free with GitHub Pages
1. Create a GitHub repository named `ranjeet-portfolio`.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL it provides.

Before publishing, check that the resume contains only details you want to share publicly.
